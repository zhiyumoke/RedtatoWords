亮点

为「批量找选题」这件事做的一整套细节

从采集、整理到导出，每一步都尽量少让你动手。

  • 批量搜索词模式

    一次贴进多个搜索词（空格分隔），程序逐个跑完并汇总到同一个列表，自动合并去重。想一次覆盖一整批选题时最省事。

  • 双通道采集

    同时监听网络响应与页面内容两条通道，两路结果取并集。单条通道漏掉的长尾联想词，另一条通常能补上。

  • 自动分词 + TAG 云

    候选词自动拆词、去重、统计词频。标签支持点击多选，也能拖拽组合，例如「好喝」拖到「搭配」上合成「搭配 好喝」。

  • 轮次扩展

    基于当前候选词与 TAG 生成下一轮搜索词，一轮接一轮逐层扩展。顶部时间线记录每一轮，随时可以回退重来。

  • 一键复制与导出

    复制全部、导出 TXT / CSV / Excel / JSON、删除选中、整表清空。导出时若已选中若干条，就只导出选中的部分。

  • 成就系统（彩蛋）

    藏了一些隐藏条件的成就，解锁时右下角会弹出提示，随时能在成就面板里回看。纯粹是好玩。

  • 深浅色主题

    默认跟随系统设置，白天黑夜自动切换，长时间整理词表也不刺眼。

  • 纯本地运行

    搜索词、候选词、标签与历史记录都只写在本机的用户数据目录，不经过任何第三方服务。

  • 内置会话窗口登录

    在软件内置的会话窗口里登录一次，登录态保存在本机独立分区，下次启动依然有效；之后的采集过程对用户不可见。

  • 自动检查更新

    启动时自动比对最新版本，发现新版本会在界面里提示，一键下载安装，不用手动换包。

常见问题

上手前你大概会想问的

需要登录平台的账号吗？

需要，但只需要一次。软件里有内置的会话窗口，在窗口里完成登录后，登录态会保存在本机的独立分区，之后再打开就能直接采集。

我的数据会被上传到什么地方吗？

不会。这是纯本地工具：搜索词、候选词、TAG 和历史记录都存放在本机用户数据目录，不经过任何第三方服务，也没有账号体系。

采集的时候我还能正常用电脑吗？

可以。采集在内置的会话窗口里独立进行，整个采集过程对用户不可见，不会抢占你正在使用的前台窗口。

结果能导出成什么格式？

一键复制到剪贴板，或者导出成 TXT / CSV / Excel / JSON。列表支持单选、Ctrl 多选、全选与筛选，导出时只导出选中的部分也没问题。

支持哪些系统？

当前提供 Windows x64 的安装包（NSIS）与免安装压缩包，两个都在 Releases 页面里。其他平台的支持情况请看仓库说明。

怎么更新到新版本？

软件启动时会自动检查更新。发现新版本后会在界面里给出提示，点一下即可下载并安装，不需要手动卸载重装。
